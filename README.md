# Eye检查记录助手

把零散的眼科检查单，整理成一条清晰的时间线。

**开源 · 健康管理记录工具 · 不构成医疗诊断**

👉 项目介绍页：仓库根目录 `index.html`（可直接用 GitHub Pages 打开）

## 两种形态

| 形态 | 目录 | 定位 |
|---|---|---|
| Eye检查记录助手 · 微信小程序 | [`wechat-mini/`](wechat-mini/) | 随身记录，手机拍照即传，云端按用户隔离 |
| Eye检查记录助手 · 网页版简洁汇总 | [`web/`](web/) | 本地/服务器部署，批量 OCR 归档与深度核对 |

两者共用同一套指标口径与展示逻辑：右眼蓝色、左眼橙色，同类指标同色。

## 核心能力

- 支持照片、图片、PDF 上传，自动解析为结构化指标
- **按日期合并**：同一天多份报告合并为一个批次，指标按日期归集
- **双眼分色**：右眼蓝 / 左眼橙；每项指标独立一行
- **散瞳标记**：仅散瞳 SE 作为远视储备参考，避免误读
- 关键指标：眼轴长度 AL、球镜 S、柱镜 C、等效球镜 SE、角膜散光、裸眼视力、瞳距 PD
- 网页版：趋势曲线、原值明细、就诊出示限时只读链接
- 小程序：手机号登录、多档案云端隔离、同日原件合并长图导出、删除档案级联清理

## 快速开始

### 网页版（本地）

需要 Python 3.10+ 与 Tesseract OCR（含 `chi_sim` 中文包）：

```bash
cd web
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

打开 <http://127.0.0.1:8765/>。首次启动自动建库（`data/phr_eye.db`）。

### 微信小程序

用微信开发者工具导入 `wechat-mini/` 目录：

- AppID：`wx579e302b755a02c3`
- 菜单 → 工具 → 构建 npm
- 编译预览 / 真机调试

对外发布前需在微信公众平台配置 request 合法域名，并在后台填写用户隐私保护指引。

## 隐私与合规

- 网页版原始报告与数据库仅保存在本地，不上传第三方
- 小程序登录后数据存入云端，按用户身份隔离；删除档案时级联删除云端文件
- 明示隐私政策、用户同意与删除权
- **本工具为健康管理记录工具，不构成医疗诊断、治疗建议或用药指导。数值请以纸质原件为准。**
