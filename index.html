Capabilities

从照片到汇总，只需几步

围绕真实报告设计，保留设备原始数值，不臆造、不混淆散瞳与非散瞳数据。

01

拍照上传与识别

照片、图片、PDF 均可；支持电脑验光单、眼生物测量单、视力检查等多种版式。

02

双眼分色展示

右眼固定蓝色、左眼固定橙色；同类指标同色，一眼分辨眼别与类别。

03

按日期合并批次

同一天上传的多份报告合并为一条，指标按日期归集，不再重复出现。

04

散瞳状态可标记

散瞳检查单独标记，只有散瞳 SE 才作为远视储备参考，避免误读。

05

关键指标追踪

眼轴长度、球镜、柱镜、等效球镜、角膜散光、裸眼视力、瞳距逐项记录。

06

原始报告可取回

同日图片合并成长图预览下载，PDF 原件逐个打开，随时核对纸质单据。

Simple summary

简洁汇总：每项指标一行，双眼一目了然

最近一次关键指标按「检查项目 / 右眼 / 左眼」三列呈现；某项若最近一次未测，则取更早记录并标注日期。

隐私与安全

  • 网页版原始报告与数据库保存在本地，不上传第三方
  • 小程序登录后数据存入云端，按用户身份隔离（RLS）
  • 原始文件按用户目录存储，删除档案时级联删除
  • 明示同意的隐私政策、删除权与免责说明
  • 就诊出示为限时只读链接，可随时撤销

Get started

快速开始

仓库内已包含完整源码。网页版本地运行；小程序用微信开发者工具导入即可预览。

网页版 · 本地运行

cd web
pip install fastapi uvicorn pillow \
  pytesseract python-multipart
python -m uvicorn app.main:app \
  --host 127.0.0.1 --port 8765

浏览器打开 http://127.0.0.1:8765/ 。需本机安装 Tesseract（含 chi_sim 中文包）。首次启动自动建库。
